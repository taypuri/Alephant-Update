# Human Academy Clone

Este é um clone de landing page inspirado no site Human Academy AI.

## Estrutura de Arquivos

```
/humanacademy-clone-exact/
├── assets/
│   └── images/       # Imagens usadas no site
├── css/
│   ├── animations.css  # Animações e efeitos visuais 
│   ├── reset.css       # Reset CSS para consistência entre navegadores
│   └── styles.css      # Estilos principais do site
├── index.html        # Arquivo HTML principal
└── js/
    └── script.js     # JavaScript com interações e animações
```

## Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Para desenvolvimento, use um servidor local:
   ```
   python3 -m http.server 8000
   ```
   E acesse: http://localhost:8000

## Personalização

- Edite o HTML para alterar textos e estrutura
- Ajuste as cores no arquivo CSS (variáveis no topo do arquivo styles.css)
- Modifique as animações em animations.css
- Adapte o JavaScript conforme necessário em script.js
